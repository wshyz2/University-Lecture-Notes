1 Graph 基础概念

什么是 Graph？

Graph（图）是一种非线性数据结构，用来表示物体之间的连接关系。

Graph 的正式定义：

Graph G = (V, E)，其中：

  • V = 顶点集合（Vertices/Nodes）
  • E = 边集合（Edges）- 定义顶点之间的连接
💡 记忆技巧：

图 = 节点 + 连线。想象一个社交网络：每个人是一个节点，友谊关系是连线。

Graph vs Tree（图 vs 树）

你可能已经学过树。图和树有什么区别？

特性 Tree（树） Graph（图）
是否有环（Cycle） ❌ 无环 ✓ 可能有环
是否有根（Root） ✓ 有一个根节点 ❌ 无根节点
连通性 连通的 可能不连通
父子关系 有明确的父子关系 只有邻接关系
重要：树是图的特殊情况！

树 = 没有环 + 有根节点 的图

Graph 的基本术语

1. Vertex / Node（顶点/节点）

图中的个体单位。例如：社交网络中的用户。

2. Edge（边）

连接两个顶点的线。例如：两个用户之间的友谊。

3. Degree（度数）

一个顶点连接的边的数量。

例子： 如果顶点 V 有 4 条边连接，则 degree(V) = 4

4. Adjacency（邻接）

两个顶点如果由一条边连接，则称它们是邻接的。

5. Path（路径）

一个节点序列，其中每个节点通过边连接到下一个节点。

例子： A → B → D → C 是一条路径

6. Cycle（环）

一条从某个节点开始，最后又回到该节点的路径。

7. Distance（距离）

两个节点之间最短路径上的边数。

如果两个节点不连通，距离定义为 ∞（无穷大）。

Graph 的分类

📌 按边的方向分类

Undirected Graph（无向图）

边没有方向。如果 A 连接到 B，则 B 也连接到 A。

例子： Facebook 好友关系

Directed Graph（有向图）

边有方向。A → B 不一定意味着 B → A。

例子： Twitter 关注关系

📌 按权重分类

Unweighted Graph（无权图）

所有边的权重都相同（通常为1）。

Weighted Graph（加权图）

边有权重值。

例子： 城市间的距离、网络延迟

📝 例子：理解度数

看这个图：

    A --- B
    |     |
    D --- C

顶点度数：

  • A: degree = 2（连接到 B 和 D）
  • B: degree = 2（连接到 A 和 C）
  • C: degree = 2（连接到 B 和 D）
  • D: degree = 2（连接到 A 和 C）

有趣的事实： 所有度数之和 = 2 × 边数 = 2 × 4 = 8

2 Graph 表示方法

为什么需要表示方法？

Graph 在计算机中是抽象的。我们需要具体的数据结构来存储和操作它。有两种主要的表示方法：

  1. Adjacency Matrix（邻接矩阵） - 使用2D数组
  2. Adjacency List（邻接表） - 使用链表或字典

我们需要选择合适的表示方法，因为它直接影响算法的效率！

3 Adjacency Matrix（邻接矩阵）

邻接矩阵的思想

邻接矩阵使用一个 n × n 的2D数组来表示图，其中 n 是顶点数。

矩阵中的值：
  • matrix[i][j] = 1（或权重）：顶点 i 和 j 之间有边
  • matrix[i][j] = 0：顶点 i 和 j 之间没有边

📝 例子：无权无向图的邻接矩阵

这个图：

    a --- b
    |   / |
    | /   |
    c --- d

顶点标记：a=0, b=1, c=2, d=3

邻接矩阵：

a b c d
a 0 1 1 0
b 1 0 1 1
c 1 1 0 1
d 0 1 1 0

观察：

  • ✓ 矩阵是对称的（因为无向图）
  • ✓ 对角线都是0（没有自环）

加权图的邻接矩阵

对于加权图，我们在矩阵中存储边的权重，而不是0/1。

📝 例子：加权无向图

    a --5-- b
    |        |
    4        6
    |        |
    c --2-- d

邻接矩阵：

a b c d
a 0 5 4 0
b 5 0 0 6
c 4 0 0 2
d 0 6 2 0

有向图的邻接矩阵

对于有向图，矩阵不是对称的。matrix[i][j] 表示从 i 指向 j 的边。

📝 例子：有向加权图

    a --5→ b
    ↑      ↓ 6
    4      ↓
    ↑      c
    ↑ 2    ↑
    └──────┘

邻接矩阵：

a b c
a 0 5 0
b 0 0 6
c 4 0 0

注意：matrix[2][0] = 4 但 matrix[0][2] = 0，因为只有 c → a 的边，没有 a → c 的边。

邻接矩阵的操作复杂度

操作 时间复杂度 说明
存储空间 O(n²) 需要 n × n 的矩阵
insertVertex O(n) 需要添加新行和新列
removeVertex O(n) 需要删除行和列
insertEdge O(1) 直接更新矩阵元素
removeEdge O(1) 直接更新矩阵元素
getEdges(v) O(n) 需要扫描整行
areAdjacent(u,v) O(1) 直接查询矩阵元素
何时使用邻接矩阵？
  • ✓ 图是密集的（边很多）
  • ✓ 需要快速检查两个顶点是否相邻
  • ✓ 顶点数相对较小
  • ❌ 稀疏图（边很少）- 会浪费空间

4 Adjacency List（邻接表）

邻接表的思想

邻接表使用一个字典（或哈希表），其中：

  • 键（Key）：顶点
  • 值（Value）：该顶点的所有邻接顶点的链表
邻接表的优点：
  • ✓ 只存储存在的边（节省空间）
  • ✓ 对于稀疏图非常高效

📝 例子：无向图的邻接表

同样的图：

    a --- b
    |   / |
    | /   |
    c --- d

邻接表表示：

a → [b, c]

b → [a, c, d]

c → [a, b, d]

d → [b, c]

比较：

  • 邻接矩阵：需要 4×4 = 16 个位置
  • 邻接表：只需要存储 8 条边引用（每条边存2次，因为无向）

有向图的邻接表

对于有向图，邻接表只列出出边（outgoing edges）。

📝 例子：有向图

    a → b
    ↓   ↓
    c ← d

邻接表表示：

a → [b, c]

b → [d]

c → []

d → [c]

邻接表的操作复杂度

操作 时间复杂度 说明
存储空间 O(n+m) n 个顶点 + m 条边
insertVertex O(1) 添加新键到字典
removeVertex O(deg(v)) 删除 v 的所有邻接
insertEdge O(1) 添加到链表
removeEdge min(deg(u), deg(v)) 搜索度数较小的顶点
getEdges(v) O(deg(v)) 返回 v 的邻接表
areAdjacent(u,v) min(deg(u), deg(v)) 搜索邻接表
💡 记住 deg(v)：

deg(v) 表示顶点 v 的度数（连接边数）。对于稀疏图，这通常远小于 n。

Python 实现邻接表

# 邻接表实现 class Graph: def __init__(self): self.edges = {} def insertVertex(self, v): """添加顶点""" if v not in self.edges: self.edges[v] = [] def insertEdge(self, u, v): """添加边（无向）""" self.insertVertex(u) self.insertVertex(v) if v not in self.edges[u]: self.edges[u].append(v) if u not in self.edges[v]: self.edges[v].append(u) def getEdges(self, v): """获取顶点 v 的所有邻接顶点""" return self.edges.get(v, []) def areAdjacent(self, u, v): """检查 u 和 v 是否邻接""" # 搜索度数较小的顶点 if len(self.edges[u]) <= len(self.edges[v]): return v in self.edges[u] else: return u in self.edges[v] # 使用例子 g = Graph() g.insertEdge('a', 'b') g.insertEdge('a', 'c') g.insertEdge('b', 'c') g.insertEdge('b', 'd') print(g.getEdges('b')) # ['a', 'c', 'd'] print(g.areAdjacent('a', 'b')) # True print(g.areAdjacent('a', 'd')) # False
何时使用邻接表？
  • ✓ 图是稀疏的（边较少）
  • ✓ 需要遍历图的所有顶点和边
  • ✓ 顶点数可能很大
  • ❌ 需要快速检查单个边存在性（比邻接矩阵慢）

邻接矩阵

空间： O(n²)

检查边： O(1)

遍历邻接： O(n)

最佳用途： 密集图

邻接表

空间： O(n+m)

检查边： O(deg(v))

遍历邻接： O(deg(v))

最佳用途： 稀疏图

5 Graph Traversal（图遍历）

为什么需要遍历？

遍历是访问图中每个顶点和边的过程。就像在迷宫中探索，我们需要一个系统的方法来确保不遗漏任何地方。

关键挑战：
  • ❌ 图没有根节点，从哪里开始？ → 任意选择一个起点
  • ❌ 图可能有环，怎样避免重复访问？ → 维护已访问列表
  • ❌ 图可能不连通，怎样访问所有顶点？ → 多次启动遍历

两种主要遍历方法

有两种经典的图遍历方法：

  1. BFS（Breadth First Search） - 广度优先搜索
  2. DFS（Depth First Search） - 深度优先搜索

两种方法都有相同的时间复杂度 O(n + m)，但访问顺序不同。

6 BFS（广度优先搜索）

BFS 的核心思想

BFS 像波纹一样逐层扩散。它首先访问起点的所有邻接顶点，然后访问那些顶点的邻接顶点，以此类推。

使用的数据结构： Queue（队列）

遵循 FIFO（先进先出）原则

BFS 算法步骤

  1. 选择一个起始顶点，加入队列
  2. 当队列不为空时：
    • 从队列前端移除一个顶点
    • 检查它的所有邻接顶点
    • 如果邻接顶点未被访问，标记为已访问并加入队列

📝 BFS 执行步骤详解

图：

        A
       / \
      B   C
      |\ /|
      D E F
          |
          G

从 A 开始的 BFS：

初始状态：

Queue: [A], Visited: {A}

步骤 1： 取出 A

A 的邻接顶点：B, C

Queue: [B, C], Visited: {A, B, C}

步骤 2： 取出 B

B 的邻接顶点：A(已访问), C(已访问), D, E

Queue: [C, D, E], Visited: {A, B, C, D, E}

步骤 3： 取出 C

C 的邻接顶点：A(已访问), B(已访问), E(已访问), F

Queue: [D, E, F], Visited: {A, B, C, D, E, F}

... 继续 ...

访问顺序： A, B, C, D, E, F, G

BFS Python 实现

from collections import deque def bfs(graph, start): """ BFS 遍历 graph: 邻接表表示的图（字典） start: 起始顶点 """ queue = deque() visited = set() queue.append(start) visited.add(start) result = [] while queue: vertex = queue.popleft() # 从队列前端移除 result.append(vertex) # 检查所有邻接顶点 for neighbor in graph[vertex]: if neighbor not in visited: visited.add(neighbor) queue.append(neighbor) return result # 使用例子 graph = { 'A': ['B', 'C'], 'B': ['A', 'C', 'D', 'E'], 'C': ['A', 'B', 'E', 'F'], 'D': ['B'], 'E': ['B', 'C'], 'F': ['C', 'G'], 'G': ['F'] } print(bfs(graph, 'A')) # ['A', 'B', 'C', 'D', 'E', 'F', 'G']

BFS 的重要特性

1. 最短路径（无权图）

BFS 找到的距离是边数最少的距离。

2. 距离和前驱

通过记录距离和前驱顶点，可以构建 MST（最小生成树）。

📝 BFS 找最短路径

改进 BFS，记录距离和前驱：

def bfs_with_distance(graph, start): """ BFS 并记录距离和前驱 """ queue = deque() distance = {start: 0} predecessor = {start: None} queue.append(start) while queue: vertex = queue.popleft() for neighbor in graph[vertex]: if neighbor not in distance: distance[neighbor] = distance[vertex] + 1 predecessor[neighbor] = vertex queue.append(neighbor) return distance, predecessor # 使用例子 distance, predecessor = bfs_with_distance(graph, 'A') # 找 A 到 G 的最短路径 def get_path(predecessor, start, end): path = [] current = end while current is not None: path.append(current) current = predecessor[current] return path[::-1] print(distance) # {'A': 0, 'B': 1, 'C': 1, 'D': 2, ...} print(get_path(predecessor, 'A', 'G')) # ['A', 'C', 'F', 'G']

BFS 对不连通图的处理

如果图有多个连通分量，一次 BFS 只能访问一个分量。需要多次启动 BFS 来访问所有顶点。

def bfs_all_components(graph): """ 处理不连通图：多次 BFS """ visited = set() components = [] for vertex in graph: if vertex not in visited: # 从未访问的顶点启动 BFS component = bfs_single(graph, vertex, visited) components.append(component) return components def bfs_single(graph, start, visited): """单次 BFS，修改外部 visited 集合""" queue = deque() queue.append(start) visited.add(start) component = [] while queue: vertex = queue.popleft() component.append(vertex) for neighbor in graph[vertex]: if neighbor not in visited: visited.add(neighbor) queue.append(neighbor) return component

BFS 的时间和空间复杂度

时间复杂度: O(n + m)

每个顶点入队和出队一次：O(n) 每条边被检查一次：O(m)

空间复杂度: O(n)

队列最坏情况下存储 O(n) 个顶点（树的最宽层）

7 DFS（深度优先搜索）

DFS 的核心思想

DFS 像钻洞一样深入。它尽可能远地沿着一条路径探索，直到遇到死胡同，才回溯探索其他分支。

使用的数据结构： Stack（栈）或递归

遵循 LIFO（后进先出）原则

DFS 算法步骤

  1. 选择一个起始顶点，加入栈
  2. 当栈不为空时：
    • 查看栈顶顶点（不弹出）
    • 如果有未访问的邻接顶点，选择第一个，标记为已访问并压入栈
    • 如果没有未访问的邻接顶点，弹出该顶点

📝 DFS 执行步骤详解

同样的图：

        A
       / \
      B   C
      |\ /|
      D E F
          |
          G

从 A 开始的 DFS：

初始： Stack: [A], Visited: {A}

步骤 1-2： 从 A 探索到 B

Stack: [A, B], Visited: {A, B}

步骤 3： 从 B 探索到 D

Stack: [A, B, D], Visited: {A, B, D}

步骤 4： D 没有未访问邻接顶点，回溯

Stack: [A, B], Visited: {A, B, D}

步骤 5： 从 B 探索到 E

Stack: [A, B, E], Visited: {A, B, D, E}

... 继续 ...

访问顺序： A, B, D, E, C, F, G

DFS Python 实现（迭代版）

def dfs(graph, start): """ DFS 遍历（迭代版，使用栈） graph: 邻接表表示的图（字典） start: 起始顶点 """ stack = [start] visited = {start} result = [] while stack: vertex = stack.pop() # 从栈顶取出 result.append(vertex) # 检查所有邻接顶点 for neighbor in reversed(graph[vertex]): if neighbor not in visited: visited.add(neighbor) stack.append(neighbor) return result # 使用例子 graph = { 'A': ['B', 'C'], 'B': ['A', 'C', 'D', 'E'], 'C': ['A', 'B', 'E', 'F'], 'D': ['B'], 'E': ['B', 'C'], 'F': ['C', 'G'], 'G': ['F'] } print(dfs(graph, 'A')) # ['A', 'B', 'D', 'E', 'C', 'F', 'G']

DFS 的递归实现（更优雅）

def dfs_recursive(graph, vertex, visited=None): """ DFS 遍历（递归版） """ if visited is None: visited = set() visited.add(vertex) result = [vertex] for neighbor in graph[vertex]: if neighbor not in visited: result.extend(dfs_recursive(graph, neighbor, visited)) return result # 使用例子 print(dfs_recursive(graph, 'A')) # ['A', 'B', 'C', 'D', 'E', 'F', 'G']

DFS vs BFS 对比

BFS（广度优先）

数据结构： Queue（队列）

访问顺序： 逐层访问

空间： O(最宽层宽度)

最短路径： ✓ 可找最短距离

应用： 最短路径、连通性

DFS（深度优先）

数据结构： Stack（栈）

访问顺序： 深入探索

空间： O(树的高度)

最短路径： ✗ 找不到最短距离

应用： 拓扑排序、环检测

💡 何时用哪个？
  • BFS： 需要找最短路径、测试连通性
  • DFS： 需要找环、做拓扑排序、空间有限

DFS 的时间和空间复杂度

时间复杂度: O(n + m)

同 BFS，每个顶点和边都被访问一次

空间复杂度: O(h)，其中 h 是树的高度

栈最坏情况下存储沿着最长路径的顶点

8 实战案例：Number of Islands

问题描述

给定一个 n × m 的网格，包含 'L'（陆地）和 'W'（水）。计算总共有多少个岛屿（相邻的陆地形成一个岛屿）。

📝 例子

grid = [
    ['L', 'L', 'W', 'W', 'W'],
    ['W', 'L', 'W', 'W', 'L'],
    ['L', 'W', 'W', 'L', 'L'],
    ['W', 'W', 'W', 'W', 'W'],
    ['L', 'W', 'L', 'L', 'W']
]

答案：4 个岛屿

问题分析

这个问题可以用图论解决：

  • 每个陆地格子是一个顶点
  • 相邻的陆地（上下左右）有边连接
  • 一个岛屿 = 一个连通分量
  • 问题 = 计数连通分量数
解法思路：

遍历网格，每当找到未访问的陆地，就启动一次 DFS/BFS，将整个岛屿标记为已访问，计数器加 1。

DFS 解法

def countIslands(grid): """ 计算岛屿数量（DFS 解法） """ if not grid or not grid[0]: return 0 n = len(grid) # 行数 m = len(grid[0]) # 列数 islands = 0 visited = [[False] * m for _ in range(n)] def dfs(r, c): """DFS 标记整个岛屿""" visited[r][c] = True # 四个方向：上、右、左、下 directions = [(-1, 0), (0, 1), (0, -1), (1, 0)] for dr, dc in directions: nr, nc = r + dr, c + dc # 检查新位置是否在范围内、是陆地且未访问 if 0 <= nr < n and 0 <= nc < m and \ grid[nr][nc] == 'L' and not visited[nr][nc]: dfs(nr, nc) # 遍历网格 for i in range(n): for j in range(m): # 找到未访问的陆地，启动 DFS if grid[i][j] == 'L' and not visited[i][j]: dfs(i, j) islands += 1 return islands # 使用例子 grid = [ ['L', 'L', 'W', 'W', 'W'], ['W', 'L', 'W', 'W', 'L'], ['L', 'W', 'W', 'L', 'L'], ['W', 'W', 'W', 'W', 'W'], ['L', 'W', 'L', 'L', 'W'] ] print(countIslands(grid)) # 4

BFS 解法

from collections import deque def countIslandsBFS(grid): """ 计算岛屿数量（BFS 解法） """ if not grid or not grid[0]: return 0 n = len(grid) m = len(grid[0]) islands = 0 visited = [[False] * m for _ in range(n)] def bfs(start_r, start_c): """BFS 标记整个岛屿""" queue = deque([(start_r, start_c)]) visited[start_r][start_c] = True directions = [(-1, 0), (0, 1), (0, -1), (1, 0)] while queue: r, c = queue.popleft() for dr, dc in directions: nr, nc = r + dr, c + dc if 0 <= nr < n and 0 <= nc < m and \ grid[nr][nc] == 'L' and not visited[nr][nc]: visited[nr][nc] = True queue.append((nr, nc)) # 遍历网格 for i in range(n): for j in range(m): if grid[i][j] == 'L' and not visited[i][j]: bfs(i, j) islands += 1 return islands print(countIslandsBFS(grid)) # 4

执行过程图解

📝 逐步执行过程

初始网格：

L L W W W
W L W W L
L W W L L
W W W W W
L W L L W

岛屿标记（最终）：
1 1 0 0 0
0 1 0 0 2
3 0 0 2 2
0 0 0 0 0
4 0 4 4 0

执行流程：

  1. 扫描到 (0,0)='L'，未访问，启动 DFS → 标记岛屿 1，计数=1
  2. 继续扫描，找到 (1,4)='L'，未访问，启动 DFS → 标记岛屿 2，计数=2
  3. 继续扫描，找到 (2,0)='L'，未访问，启动 DFS → 标记岛屿 3，计数=3
  4. 继续扫描，找到 (4,0)='L'，未访问，启动 DFS → 标记岛屿 4，计数=4
  5. 扫描完成，返回 4

时间和空间复杂度分析

方面 复杂度 说明
时间 O(n × m) 每个格子最多被访问一次
空间（DFS） O(n × m) visited 数组 + 递归栈
空间（BFS） O(n × m) visited 数组 + 队列
💡 为什么两种方法空间都是 O(n×m)？

虽然 DFS 使用栈、BFS 使用队列，但最坏情况下，整个网格都是陆地，此时最大的中间存储都是 O(n×m)。

题 2：邻接矩阵 vs 邻接表

问： 为什么稀疏图应该用邻接表而不是邻接矩阵？

查看答案

稀疏图的边数 m ≪ n²，使用邻接矩阵会浪费大量空间：

  • 邻接矩阵：O(n²) 空间，大部分为 0
  • 邻接表：O(n+m) 空间，只存储实际的边

查看答案
def isConnected(graph, u, v): """判断两个顶点是否连通""" visited = set() def dfs(vertex): if vertex == v: return True visited.add(vertex) for neighbor in graph[vertex]: if neighbor not in visited: if dfs(neighbor): return True return False return dfs(u) # 使用 graph = {'A': ['B'], 'B': ['A', 'C'], 'C': ['B'], 'D': []} print(isConnected(graph, 'A', 'C')) # True print(isConnected(graph, 'A', 'D')) # False

📌 核心要点总结

必须记住的概念

1️⃣ Graph Basics

  • Graph G = (V, E) - 顶点集合 + 边集合
  • 无向图 vs 有向图 - 边是否有方向
  • 无权图 vs 加权图 - 边是否有权重

2️⃣ Graph 表示

  • 邻接矩阵：O(n²) 空间，O(1) 检查边
  • 邻接表：O(n+m) 空间，O(deg(v)) 检查边

3️⃣ 图遍历

  • BFS：逐层探索，找最短路径，O(n+m)
  • DFS：深入探索，检测环，O(n+m)
