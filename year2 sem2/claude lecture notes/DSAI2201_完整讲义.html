📊 Lecture 9: 图论 (Graph Theory)

1️⃣ 图的基本概念

什么是图？

图（Graph）是一种非线性数据结构（non-linear data structure），用来表示对象之间的关系。

图的正式定义：
图 G = (V, E)，其中：
  • V = 顶点集合（Vertices/Nodes）- 图中的各个点
  • E = 边集合（Edges）- 连接顶点的线

图与树的区别

特性 树 (Tree) 图 (Graph)
是否有循环 没有循环 (Acyclic) 可能有循环 (可有Cycle)
是否有根节点 有一个根节点 (Rooted) 没有根节点
连接性 必须连通 可以不连通

关键概念

📌 顶点的度数 (Degree)

度数 = 连接到该顶点的边数

📌 路径与循环

路径 (Path)： 一系列顶点序列，相邻顶点通过边连接

循环 (Cycle)： 从一个顶点出发，最后回到该顶点的路径

📌 距离 (Distance)

两个顶点之间的距离定义为连接它们的最短路径上的边数

2️⃣ 图的分类与表示

无向图 vs 有向图

无向图 (Undirected Graph)

边没有方向，是对称的。如果A连到B，则B也连到A。

有向图 (Directed Graph)

边有方向，用箭头表示。需要区分 in-degree 和 out-degree。

图的表示方法

邻接矩阵 (Adjacency Matrix)

用二维矩阵表示顶点之间的连接

存储空间：O(n²) | 查询边：O(1) | 获取邻接顶点：O(n)

邻接表 (Adjacency List)

用字典存储每个顶点的邻接顶点列表

存储空间：O(V+E) | 查询边：O(degree) | 获取邻接顶点：O(degree)
💡 选择建议： 稀疏图→邻接表，密集图→邻接矩阵

3️⃣ 图的遍历

广度优先搜索 (BFS)

从一个顶点开始，逐层向外访问所有顶点。使用队列。

🔍 BFS步骤

1. 从起点加入队列
2. 取出队头顶点，访问所有未访问邻接顶点
3. 重复直到队列为空
时间复杂度：O(V + E) | 空间复杂度：O(V)

深度优先搜索 (DFS)

从一个顶点开始，尽可能深地访问。使用栈或递归。

🔍 DFS步骤

1. 访问当前顶点
2. 递归访问所有未访问邻接顶点
3. 回溯
时间复杂度：O(V + E) | 空间复杂度：O(V)

BFS vs DFS

特性 BFS DFS
数据结构 队列 (Queue) 栈 (Stack) 或递归
搜索方向 逐层向外（水平） 尽可能深（垂直）
最短路径 ✅ 找得到 ❌ 找不到

🎯 Lecture 10: 贪心算法 (Greedy Algorithm)

1️⃣ 贪心算法基础

什么是贪心算法？

贪心算法是一种在每一步都做出局部最优选择的问题解决策略。

核心思想：
在每一步选择看起来最优的选项，希望找到全局最优解

关键特点：
  • 无回溯：做出选择后不再改变
  • 高效：通常只需一遍扫描
  • 非总是最优：某些问题不适用

四个关键特性

特性 说明
局部优化（Local Optimization） 每一步选择当前看起来最好的选项
无回溯（No Backtracking） 一旦做出选择，就不再改变
高效性（Efficiency） 通常有较低的时间复杂度
非总是最优（Not Always Optimal） 不能保证全局最优解

2️⃣ 区间调度问题 (Interval Scheduling)

问题定义

给定n个工作，每个工作j有开始时间sj和结束时间fj。两个工作兼容当且仅当不重叠。目标：找最大数量互相兼容的工作。

最优贪心策略

🎯 按结束时间排序

步骤1： 按结束时间fj排序工作（从早到晚）
步骤2： 逐个检查工作，选择与已选工作兼容的工作
步骤3： 重复直到无更多兼容工作 
def greedy_schedule(jobs):
    # jobs = [(start, finish), ...]
    jobs.sort(key=lambda x: x[1])
    results = []
    last_finish = 0

    for start, finish in jobs:
        if start >= last_finish:
            results.append((start, finish))
            last_finish = finish

    return results
时间复杂度：O(n log n)（排序）| 空间复杂度：O(n)
✅ 正确性： 选择结束最早的工作为后续工作留下最多时间

3️⃣ 最小生成树 (MST)

基本概念

给定连通、无向、加权图，找生成树使其总权值最小。

生成树： 包含所有顶点和某些边、无循环的子图
最小生成树： 所有边权值之和最小的生成树

Kruskal算法：增长森林

🔍 Kruskal思路

1. 按权值从小到大排序所有边
2. 遍历排序后的边，选择不形成循环的边
3. 重复直到选择V-1条边
时间复杂度：O(E log E) | 空间复杂度：O(V)

Prim算法：增长树

🔍 Prim思路

1. 从任意顶点开始，加入已选集合
2. 找连接已选和未选的最小权边
3. 将另一端加入已选集合，重复
时间复杂度：O(V²) 或 O((V+E) log V) | 空间复杂度：O(V)

Kruskal vs Prim

特性 Kruskal Prim
思想 增长森林 增长一棵树
关键结构 并查集 (Union-Find) 优先队列
适用图 稀疏图 密集图

💡 Lecture 11: 动态规划 (Dynamic Programming)

1️⃣ 动态规划基础

什么是动态规划？

动态规划是一种优化算法设计技术，用于解决具有重叠子问题和最优子结构的问题。

核心思想：
将大问题分解为小问题，保存小问题答案，避免重复计算，由小问题答案组成大问题答案

与分治法的区别

分治法 (Divide & Conquer)

子问题互不相关。例：快速排序、合并排序

动态规划 (Dynamic Programming)

子问题互相重叠。例：斐波那契、背包问题

2️⃣ 斐波那契序列：DP的入门例子

问题定义

递推式： Fn = Fn-1 + Fn-2
初始值： F0 = 0, F1 = 1
数列： 0, 1, 1, 2, 3, 5, 8, 13, 21, ...

方法1：朴素递归（效率极低）

def fibonacci_naive(n):
    if n == 0:
        return 0
    if n == 1:
        return 1
    return fibonacci_naive(n-1) + fibonacci_naive(n-2)
时间复杂度：O(2n) 指数级！ | 问题：大量重复计算

方法2：自上而下DP（记忆化）

def fibonacci_memo(n, memo=None):
    if memo is None:
        memo = {}

    if n in memo:
        return memo[n]

    if n == 0:
        return 0
    if n == 1:
        return 1

    memo[n] = fibonacci_memo(n-1, memo) + fibonacci_memo(n-2, memo)
    return memo[n]
时间复杂度：O(n) | 空间复杂度：O(n)

方法3：自下而上DP（迭代）

def fibonacci_bottom_up(n):
    F = [0, 1]
    for i in range(2, n+1):
        F.append(F[i-1] + F[i-2])
    return F[n]
时间复杂度：O(n) | 空间复杂度：O(n)

方法4：空间优化

def fibonacci_optimized(n):
    if n <= 1:
        return n
    prev, curr = 0, 1
    for _ in range(2, n+1):
        prev, curr = curr, prev + curr
    return curr
时间复杂度：O(n) | 空间复杂度：O(1)（最优！）

效率对比

方法 时间复杂度 空间复杂度
朴素递归 O(2n) O(n)
记忆化DP O(n) O(n)
迭代DP O(n) O(n)
空间优化 O(n) O(1)

3️⃣ DP的两个关键特性

特性1：最优子结构 (Optimal Substructure)
问题的最优解可由子问题的最优解组合而成

特性2：重叠子问题 (Overlapping Subproblems)
相同的子问题在求解过程中出现多次
✅ DP应用条件：
必须同时满足这两个特性！

4️⃣ 设计DP算法的步骤

🎯 标准流程

1. 定义子问题及其表示方式
2. 编写递推关系式（状态转移方程）
3. 确定基础情况（Base Cases）
4. 选择实现方法（自上而下或自下而上）
5. 计算最终答案

5️⃣ 自上而下 vs 自下而上

方面 自上而下（Top-Down Memoization） 自下而上（Bottom-Up Iteration）
思考方式 像正常递归，但保存结果 先解小问题，再解大问题
实现方式 递归 + 字典 循环 + 表格
只计算需要的 ✅ 是 ❌ 否
递归开销 有开销 无开销，更高效

6️⃣ 加权区间调度问题

问题定义

每个工作有开始时间、结束时间和权值（价值）。找不重叠工作集合使总权值最大。

DP解法

定义： OPT(j) = 前j个工作的最优权值和

递推式：
OPT(j) = max(vj + OPT(p(j)), OPT(j-1))

其中p(j)是最大兼容工作的索引
基础情况： OPT(0) = 0
时间复杂度：O(n²) 或 O(n log n) | 空间复杂度：O(n)

7️⃣ 0/1背包问题

问题定义

给定n个物品（权重wi、价值vi）和背包容量W。选择物品使总价值最大且不超容量。每个物品要么全部拿，要么都不拿。

DP解法

定义： DP[i][w] = 前i个物品，容量为w的最大价值

递推式：
DP[i][w] = max(vi + DP[i-1][w-wi], DP[i-1][w])

基础情况： DP[0][w] = 0 
def knapsack_01(weights, values, capacity):
    n = len(weights)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        for w in range(capacity + 1):
            exclude = dp[i-1][w]
            include = 0
            if weights[i-1] <= w:
                include = values[i-1] + dp[i-1][w - weights[i-1]]
            dp[i][w] = max(include, exclude)

    return dp[n][capacity]
时间复杂度：O(n × W) | 空间复杂度：O(n × W) 或 O(W)（优化）
💡 为什么0/1背包需要DP？
贪心算法在这里失败，因为不满足最优子结构
