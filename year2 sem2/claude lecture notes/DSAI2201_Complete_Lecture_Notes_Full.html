第1讲

Intro to Data Structure and Algorithm Efficiency (Big-O)

1.1 数据结构 (Data Structure)

数据结构是计算机中组织和存储数据的方式。定义了数据元素之间的逻辑关系，以及在该结构中可以进行的操作。

1.2 抽象数据类型 (Abstract Data Type, ADT)

ADT 定义了数据的逻辑性质（what），而不关心具体实现（how）。
栈 (Stack) ADT
操作: push(x), pop(), peek(), isEmpty()
特性: LIFO (Last-In-First-Out)

1.3 Python List 操作

操作 Big-O 说明
list[i] O(1) 直接访问
list.append(x) O(1) 均摊 末尾追加
list.insert(i, x) O(n) 需要移动元素
list.pop() O(1) 删除末尾
x in list O(n) 线性搜索

1.4 Algorithm Efficiency & Big-O Notation

Big-O 定义: f(n) = O(g(n)) 当存在正常数 c 和 n₀，使得对所有 n ≥ n₀，有 f(n) ≤ c·g(n)
记号 名称 例子
O(1) Constant 数组访问
O(log n) Logarithmic 二分搜索
O(n) Linear 线性搜索
O(n log n) Linearithmic 快速排序(平均)
O(n²) Quadratic 冒泡排序
O(2ⁿ) Exponential 递归斐波那契

Big-O 简化规则

• 忽略常数因子: O(5n) = O(n)
• 忽略低阶项: O(n² + n) = O(n²)
• 主导项决定: O(2ⁿ + n²) = O(2ⁿ)

例1: 嵌套循环

for i in range(n):
    for j in range(n):
        print(i, j)  # O(1)
外层 n 次，内层 n 次 → n × n = n² → O(n²)

例2: 插入排序最坏情况

比较次数 = 1 + 2 + ... + (n-1) = n(n-1)/2 → O(n²)

第2讲

LinkedList

2.1 链表的定义

链表是一种线性数据结构，由节点组成，每个节点包含数据和指向下一节点的指针。

2.2 单链表 (Singly Linked List)

class Node:
    def __init__(self, data, next=None):
        self.data = data
        self.next = next
操作 Big-O 说明
访问第i个 O(n) 需要遍历
在头部插入 O(1) 直接插入
在末尾插入 O(n) 需要找到末尾
删除节点 O(n) 需要找前驱
搜索 O(n) 线性搜索

2.3 链表 vs 数组

数组 链表
访问 O(1) O(n)
插入/删除 O(n) O(1)* (位置已知)
空间 连续 离散
缓存友好 是 否

例: 链表插入

在节点 curr 和 curr.next 之间插入新节点 new_node：
new_node.next = curr.next; curr.next = new_node
时间复杂度: O(1)

第3讲

Stack and Queue

3.1 栈 (Stack)

特性: LIFO (Last-In-First-Out)
最后进入的元素最先出去。

栈的操作

  • push(x): 在栈顶加入元素 - O(1)
  • pop(): 移除并返回栈顶元素 - O(1)
  • peek(): 查看栈顶元素 - O(1)
  • isEmpty(): 检查栈是否为空 - O(1)

栈的实现

class Stack:
    def __init__(self):
        self.items = []
    
    def push(self, x):
        self.items.append(x)
    
    def pop(self):
        if not self.isEmpty():
            return self.items.pop()
    
    def isEmpty(self):
        return len(self.items) == 0

栈的应用

  • 括号匹配检查
  • 函数调用栈
  • DFS 深度优先搜索
  • 表达式求值 (中缀转后缀)

3.2 队列 (Queue)

特性: FIFO (First-In-First-Out)
先进入的元素先出去。

队列的操作

  • enqueue(x): 在队尾加入元素 - O(1)
  • dequeue(): 移除并返回队首元素 - O(1)
  • peek(): 查看队首元素 - O(1)
  • isEmpty(): 检查队列是否为空 - O(1)

队列的实现

class Queue:
    def __init__(self):
        self.items = []
    
    def enqueue(self, x):
        self.items.append(x)
    
    def dequeue(self):
        if not self.isEmpty():
            return self.items.pop(0)
    
    def isEmpty(self):
        return len(self.items) == 0

队列的应用

  • BFS 广度优先搜索
  • 任务调度
  • 打印机队列
  • 寻找最短路径 (无权图)

例: 括号匹配

用栈检查 "(())()" 是否匹配：
遇到 '(' push，遇到 ')' pop。最后栈为空 → 匹配 ✓

第4讲

Hashing

4.1 Hash Table 基础

Hash Table 通过哈希函数将键映射到数组索引，实现平均 O(1) 的查找、插入、删除。

4.2 碰撞 (Collision) 解决方法

线性探测 (Linear Probing)

当发生碰撞时，尝试下一个空槽：
h(k, i) = (h(k) + i) mod m, i = 0, 1, 2, ...
问题: Primary Clustering - 形成大簇，效率下降

二次探测 (Quadratic Probing)

h(k, i) = (h(k) + i²) mod m, i = 0, 1, 2, ...
改善 primary clustering，但仍有 secondary clustering

双哈希 (Double Hashing)

h(k, i) = (h₁(k) + i·h₂(k)) mod m
最好的开放地址法，避免聚集

链接法 (Chaining)

每个数组位置维护一个链表。
优点: 简单、删除高效
缺点: 额外空间用于指针

例: 线性探测

keys = {76, 93, 40, 47, 10, 55}, 数组大小 = 7
hash(k) = k % 7

76 % 7 = 6 → [6]
93 % 7 = 2 → [2]
40 % 7 = 5 → [5]
47 % 7 = 5 (碰撞) → 尝试 6, 0 → [0]
方法 查询 插入 删除 问题
Linear Probing O(1) 平均 O(1) 平均 O(1) 平均 Primary Clustering
Quadratic Probing O(1) 平均 O(1) 平均 O(1) 平均 Secondary Clustering
Double Hashing O(1) 平均 O(1) 平均 O(1) 平均 最优
Chaining O(1) 平均 O(1) 平均 O(1) 平均 额外空间

第5讲

Sorting Algorithms

5.1 选择排序 (Selection Sort)

每次选择剩余未排序部分的最小元素，放到已排序部分末尾。 
def selectionSort(arr):
    for i in range(len(arr)):
        minIdx = i
        for j in range(i+1, len(arr)):
            if arr[j] < arr[minIdx]:
                minIdx = j
        arr[i], arr[minIdx] = arr[minIdx], arr[i]
最坏: O(n²), 最好: O(n²), 平均: O(n²), 空间: O(1), 不稳定

5.2 冒泡排序 (Bubble Sort)

比较相邻元素，较大的'冒泡'到后面。 
def bubbleSort(arr):
    n = len(arr)
    for i in range(n-1):
        for j in range(n-1, i, -1):
            if arr[j] < arr[j-1]:
                arr[j], arr[j-1] = arr[j-1], arr[j]
最坏: O(n²), 最好: O(n), 平均: O(n²), 空间: O(1), 稳定

5.3 插入排序 (Insertion Sort)

将每个元素插入已排序部分的正确位置（如整理扑克牌）。 
def insertionSort(arr):
    for i in range(1, len(arr)):
        j = i
        while j > 0 and arr[j] < arr[j-1]:
            arr[j], arr[j-1] = arr[j-1], arr[j]
            j -= 1
最坏: O(n²), 最好: O(n), 平均: O(n²), 空间: O(1), 稳定

5.4 快速排序 (Quick Sort)

分治算法。选枢纽 (pivot)，分成小于和大于两部分，递归排序。

分区 (Partition) 过程:

  1. 选最后元素为枢纽
  2. left 从左找第一个 > pivot 的
  3. right 从右找第一个 ≤ pivot 的
  4. left < right 时交换
  5. 重复直到 left ≥ right
  6. pivot 放正确位置
最坏: O(n²), 最好: O(n log n), 平均: O(n log n), 空间: O(log n), 不稳定

例: 快速排序

[78, 64, 51, 45, 23, 8]，枢纽=8
第一次分区 → [8, ..., ...]
递归处理左右部分

5.5 排序算法对比

算法 最好 平均 最坏 空间 稳定
Selection O(n²) O(n²) O(n²) O(1) 否
Bubble O(n) O(n²) O(n²) O(1) 是
Insertion O(n) O(n²) O(n²) O(1) 是
Quick Sort O(n log n) O(n log n) O(n²) O(log n) 否
Merge Sort O(n log n) O(n log n) O(n log n) O(n) 是
通用首选: 快速排序（平均O(n log n)，实践最快）

第6讲

Recursion

6.1 递归的三个要素

1. Base Case (基础情况): 最简单的问题，直接返回
2. Recursive Step (递归步骤): 将大问题分解为小问题
3. 信任 (Trust): 假设递归调用会正确解决小问题

例1: 阶乘

def factorial(n):
    # Base case
    if n == 0 or n == 1:
        return 1
    # Recursive step
    return n * factorial(n-1)
时间: O(n), 空间: O(n) (递归栈)

例2: 二分搜索

def binarySearch(arr, target, left, right):
    if left > right:
        return -1
    mid = (left + right) // 2
    if arr[mid] == target:
        return mid
    elif arr[mid] > target:
        return binarySearch(arr, target, left, mid-1)
    else:
        return binarySearch(arr, target, mid+1, right)
时间: O(log n), 空间: O(log n)

6.2 递归 vs 迭代

递归 迭代
代码简洁性 更清晰 更复杂
空间复杂度 O(深度) O(1)
性能 较慢 较快
栈溢出风险 有 无

6.3 重要问题：递归时间复杂度

斐波那契数列

def fib(n):
    if n <= 1:
        return n
    return fib(n-1) + fib(n-2)  # 时间: O(2^n) ❌ 太慢!
大量重复计算！fib(5) 计算 fib(3) 三次。
解: 用动态规划改为 O(n)

第7讲

Basics of Tree

7.1 树的基本概念

树是一种分层数据结构，由节点和边组成。特点: 连通、无环、有一个根节点。

7.2 树的术语

  • 根 (Root): 最上面的节点，无父节点
  • 叶 (Leaf): 无子节点的节点
  • 度 (Degree): 节点的子节点个数
  • 深度/级别: 从根到该节点的距离
  • 高度: 树的最大深度
  • 祖先/后代: 向上/向下的路径

7.3 二叉树 (Binary Tree)

每个节点最多两个子树（左子树、右子树）。 
class TreeNode:
    def __init__(self, data, left=None, right=None):
        self.data = data
        self.left = left
        self.right = right

7.4 树的遍历

前序 (Preorder): 根 → 左 → 右
中序 (Inorder): 左 → 根 → 右
后序 (Postorder): 左 → 右 → 根

例: 树 [1, 2, 3]

    1
                   / \
                  2   3
前序: 1, 2, 3
中序: 2, 1, 3
后序: 2, 3, 1

7.5 树的高度计算

def treeHeight(node):
    if node is None:
        return -1
    return 1 + max(treeHeight(node.left), treeHeight(node.right))
时间: O(n), 空间: O(h) h为高度

7.6 完全二叉树 (Complete Binary Tree)

除最后一层外，所有层都满，且最后一层从左到右连续。
重要: n个节点 → 高度 = O(log n)

第8讲

Binary Search Tree

8.1 BST 的定义

• 左子树所有节点 < 根
• 右子树所有节点 > 根
• 左右子树也都是 BST

8.2 查找 (Find)

def findInBST(node, key):
    if node is None:
        return None
    if node.key == key:
        return node
    if node.key > key:
        return findInBST(node.left, key)
    else:
        return findInBST(node.right, key)
平衡树: O(log n), 最坏链式: O(n)

8.3 插入 (Insert)

def insertInBST(node, key, value):
    if node is None:
        return BSTNode(key, value)
    if node.key > key:
        node.left = insertInBST(node.left, key, value)
    elif node.key < key:
        node.right = insertInBST(node.right, key, value)
    return node
平衡树: O(log n), 最坏: O(n)

8.4 删除 (Remove)

情况1: 无子节点 → 直接删除
情况2: 一个子节点 → 用子节点替代
情况3: 两个子节点 → 用中序后继替代

8.5 中序后继 (In-order Successor)

右子树中最小的节点（中序遍历的下一个）。 
def findInOrderSuccessor(node):
    p = node.right
    while p.left is not None:
        p = p.left
    return p

例: 删除两个子节点的节点

删除25: 找中序后继 = 30
用30替代25，再删除30

第9讲

Graph Theory

9.1 图的基础

图 G = (V, E)，V 为顶点集，E 为边集。
有向 vs 无向: 边是否有方向
加权: 边带权重（距离、成本等）

9.2 邻接表 vs 邻接矩阵

邻接矩阵 邻接表
空间 O(V²) O(V+E)
查询边 O(1) O(deg(v))
适合 稠密图 稀疏图

9.3 深度优先搜索 (DFS)

def dfs(node, visited):
    visited.add(node)
    for neighbor in node.neighbors:
        if neighbor not in visited:
            dfs(neighbor, visited)
时间: O(V+E), 空间: O(V) (递归栈)

9.4 广度优先搜索 (BFS)

from collections import deque

def bfs(start):
    visited = {start}
    queue = deque([start])
    while queue:
        node = queue.popleft()
        for neighbor in node.neighbors:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
时间: O(V+E), 空间: O(V) (队列)

DFS vs BFS

DFS BFS
数据结构 栈 队列
最短路径 否 是 (无权)
应用 拓扑排序 最短路径

9.5 最小生成树 (MST)

Kruskal 算法

  1. 按权重排序所有边
  2. 依次选择不形成环的边
  3. 直到选 V-1 条边
时间: O(E log E), 用于稀疏图

Prim 算法

  1. 从一个顶点开始
  2. 每次选最轻的出边到新顶点
  3. 直到所有顶点在 MST 中
时间: O(E log V), 用于密集图

第10讲

Greedy Algorithms

10.1 贪心法的思想

在每一步做出局部最优选择，希望找到全局最优。
关键: 局部最优 ≠ 全局最优

10.2 何时贪心有效？

• 问题有贪心选择性 (greedy choice property)
• 问题有最优子结构
• 能数学证明贪心是最优的

10.3 分数背包 (Fractional Knapsack)

贪心解:
1. 计算每项的价值/重量比
2. 按比例从大到小取
保证最优！

例

物品: (价值,重量) = (100,2), (10,2), (120,3)
容量: 4
比例: 50, 5, 40
贪心: 取 (100,2) + 1/3(120,3) = 140 ✓

10.4 0/1 背包 (Binary Knapsack)

不能取分数，贪心失败：
物品: (100,2), (10,2), (120,3)
贪心可能选 (100,2) + (10,2) = 110
但最优是 (100,2) + (120,3) = 不行 (超容量)
实际最优: (100,2) + 某物品 或只取 (120,3)
需要动态规划！

10.5 最小生成树

Kruskal 和 Prim 都是贪心，且保证最优（有数学证明）。

第11讲

Dynamic Programming

11.1 DP 的核心思想

将大问题分解为重叠子问题，用表格存储结果避免重复计算。
两个关键性质:
• 最优子结构: 最优解包含子问题最优解
• 重叠子问题: 子问题重复出现

11.2 斐波那契数列

递归 - 低效

def fib(n):
    if n <= 1:
        return n
    return fib(n-1) + fib(n-2)
    # 时间: O(2^n) ❌

DP - 高效

def fib_dp(n):
    if n <= 1:
        return n
    dp = [0] * (n + 1)
    dp[1] = 1
    for i in range(2, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]
    # 时间: O(n) ✓
时间: O(n), 空间: O(n)
还可以优化空间到 O(1) (只需要前两个值)

11.3 加权区间调度

给定任务的时间区间和价值，选非重叠任务使总价值最大。
DP 递推:
OPT(j) = max(v[j] + OPT(p[j]), OPT(j-1))
• 选j: 价值v[j] + 兼容任务最优解
• 不选j: 不包含j的最优解
时间: O(n log n) (排序) + O(n) (DP) = O(n log n)

11.4 0/1 背包问题 (DP 解法)

定义: v[j][w] = 前j项、容量w的最大价值
递推:
v[j][w] = max(v[j-1][w], v[j-1][w-wj] + valj)
• 不取: v[j-1][w]
• 取: v[j-1][w-wj] + valj

DP 表格

def knapsack(W, n, w, val):
    dp = [[0] * (W + 1) for _ in range(n + 1)]
    
    for j in range(1, n + 1):
        for cap in range(W + 1):
            # 不取
            dp[j][cap] = dp[j-1][cap]
            # 取
            if w[j-1] <= cap:
                dp[j][cap] = max(dp[j][cap],
                                  dp[j-1][cap-w[j-1]] + val[j-1])
    return dp[n][W]
时间: O(nW), 空间: O(nW)

例: 0/1 背包

物品: (价值,重量) = (100,2), (10,2), (120,3)
容量: 4
贪心: (100,2) + (10,2) = 110
DP最优: (100,2) 或 (120,3) 或其他组合
实际: (100,2) 剩2容量放不下 (10,2)？可以！= 110
或 (120,3) = 120 如果容量是5就能 (100,2)+(120,3)=220
容量4: 最优应该是 (100,2) + 其他物品
关键: DP 保证找到全局最优！

11.5 DP vs 贪心

用贪心: 分数背包、MST
用DP: 0/1背包、LCS、编辑距离、路径数
判断标准: 能否证明贪心最优？不能就用DP

11.6 其他 DP 应用

  • 最长公共子序列 (LCS): O(nm)
  • 编辑距离 (Edit Distance): O(nm)
  • 矩阵链乘法: O(n³)
  • 路径计数: O(nm)
  • 硬币兑换: O(nW)
