Q3 Linear Regression

Running Instructions:
1. Ensure R environment is installed
2. Install necessary package: ggplot2
3. Place house_prices_dataset.csv file in the same directory as regression.r
4. Run the regression.r script

Packages Used:
- ggplot2: for creating scatter plots and fitted lines

Output:
- area_price.png: Area vs Price scatter plot
- distance_price.png: Distance vs Price scatter plot
- age_price.png: Age vs Price scatter plot
- condition_price.png: Condition vs Price scatter plot
- Console output: summary/attributes/coefficients for each model, predicted price, R² values for each model, and the optimal model
